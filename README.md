"# Bookshelf" in Kotlin
1. Các thư viện hỗ trợ
- Sử dụng Retrofit để GET dữ liệu Json từ Google Book Api
- Sử dụng Coil để hiển thị ảnh từ internet
- Sử dụng Gson và Kotlin Serialization để chuyển dữ liệu từ Json sang đối tượng trong Kotlin.
- Sử dụng Coroutine để phân luồng process nhằm cải thiện chất lượng app, tối ưu hiệu năng

2. App Architeture
 - Thiết kế app theo mô hình MVVM
 - Sử dụng Dependency Injection để quản lí và kiểm soát Repository.
 - Phân chia rõ ràng Data Layer và Ui Layer
